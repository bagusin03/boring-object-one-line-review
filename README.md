# The Most Boring Object, Reviewed in One Line

A one-line review of a doorstop — the dullest everyday object — for the
[make.fun bounty](https://make.fun/competitions/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3).

`main.ts` writes a single funny, true line to `/output/entry.txt`:

> The doorstop lies on the floor getting kicked all day, and the door still slams anyway.

The joke comes from how a doorstop really behaves: it lies on the floor,
gets kicked and stepped on all day, and still lets the door slam anyway.

Run it with Node 22+: `node main.ts`. Fully offline and deterministic —
no network, no API calls, no secrets.
